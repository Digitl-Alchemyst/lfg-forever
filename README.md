# LFG Forever

*Looking for Group, Forever.*

A filterable Looking For Group browser for World of Warcraft — tank / healer / dps, level range, and text filters, with one-click **Invite** and **Request to Join** buttons. Open it with `/lfg`, `/groupfinder`, or the minimap button. The game's own Looking For Group window is left completely untouched.

## Features

- Filter by role (Tank / Healer / DPS), level range, and free text
- Show All / Groups / Players
- Sort by groups-first, level, name, or group size
- One-click Invite (solo listings) or Request to Join (group listings)
- Right-click a listing for Whisper / Invite / Request to Join / Who
- Draggable minimap button
- Never touches or hooks the game's own LFG window, so nothing taints and the Blizzard browser keeps working normally

## Slash Commands

- `/lfg` — open or close the browser
- `/lfg minimap` — show/hide the minimap button
- `/lfg reset` — recenter the window
- `/lfg help` — list commands
- `/groupfinder` — alias for `/lfg`
